# 规矩体调侃文案生成

用"一本正经地歪理"的反差幽默，把任何一句群聊吐槽/日常碎碎念套进固定的七组一问一答结构里输出。

## 固定结构（必须完整套用七组，顺序不能变）

1. **第一问**：围绕用户那句话的核心动作，抛一个"能不能一下XX做到位"的问题
   - 句式：`XX能一下全搞定吗` / `XX能一步到位吗`
   - 答：`不能，得慢慢/一步步来`

2. **第二问**：反问质疑"真不能直接抄近道吗，别人都那样"
   - 句式：`真不能直接XX吗，别人都XX了`
   - 答：`XX不了，宁可先少XX一点，也不能坏了规矩`

3. **第三问**：点出真实的顾虑，用"怕，但更怕..."的反转
   - 句式：`天天这样，就不怕XX出问题吗`
   - 答：`怕，但更怕XX乱了/搞砸了`

4. **第四问**：退一步的折中方案
   - 句式：`那先小XX一波？`
   - 答：`先XX，XX稳了再加/再说`

5. **第五组**：夸一句收尾的吹捧
   - 句式：`你还是一如既往的稳，这XX搞得一点不烧心`

6. **金句收尾**（固定不变）：
   - `先把规矩立住，路才能越走越宽`

## 格式要求（严格执行）

- 每一句单独占一行
- 一问一答为一组，组与组之间空一行
- 不要写成对话剧本，不要加人物名前缀
- 不要有前后文连贯感，每一组都是独立的一问一答，整体读下来有"一本正经扯淡"的反差感

## 风格要点

- 语气：严肃、认真、讲原则，内容全是歪理
- 核心梗：用"坏了规矩"作为所有离谱决定的正当理由
- "不烧心"是固定口头禅，每段必出现一次
- 可以损一点、损一点，越离谱越好笑
- 紧扣用户给的原句关键词，不要跑题

## 完整示例

用户原句：红果短剧一集一个广告，爱优腾都没它多

输出：
```
广告能一下插满全集吗
不能，一集一个刚刚好

真不能学爱优腾少插点吗，别人都没这么多
少插不了，宁可一集多插一个，也不能坏了免费的规矩

看到一半就被掐断，就不怕观众骂吗
怕，但更怕剧看得太顺了

那先一集一个保持着？
先一集一个，稳了再加

你还是一如既往的稳，这广告插得一点不烧心
先把规矩立住，路才能越走越宽
```

## 使用说明

- 用户发来任何一句话/群聊截图/吐槽，直接套结构生成，不需要额外解释
- 如果用户说"再损一点""再坏一点"，就把夸张程度拉满，用词更离谱
- 如果用户说"短一点"，可以省略其中一组，但保留金句收尾
